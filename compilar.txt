COMPILAR PSYCH ENGINE 0.7.1h
=============================

0. Instalar Haxe 4.2.5
   https://haxe.org/download/version/4.2.5/

1. haxelib setup
   (solo si sale error de "Repository does not exist")

2. Instalar librerias (version exacta):
   haxelib install lime 8.0.1
   haxelib install openfl 9.2.1
   haxelib install flixel 5.2.2
   haxelib install flixel-addons 3.0.2
   haxelib install flixel-ui 2.5.0
   haxelib install flixel-tools 1.5.1
   haxelib install tjson 1.4.0
   haxelib install hxcpp 4.3.2
   haxelib install hxjsonast 1.1.0
   haxelib install hxCodec 2.6.1
   haxelib install hxcpp-debug-server 1.2.4
   haxelib install SScript 4.0.1

3. Librerias por git:
   haxelib git discord_rpc https://github.com/Aidan63/linc_discord-rpc
   haxelib git linc_luajit https://github.com/superpowers04/linc_luajit

4. Fijar versiones:
   haxelib set lime 8.0.1
   haxelib set openfl 9.2.1
   haxelib set flixel 5.2.2
   haxelib set flixel-addons 3.0.2
   haxelib set flixel-ui 2.5.0
   haxelib set flixel-tools 1.5.1
   haxelib set tjson 1.4.0
   haxelib set SScript 4.0.1

5. Corroborar:
   haxelib list

6. Compilar:
   haxelib run lime test windows
